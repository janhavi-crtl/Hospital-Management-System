# 🏥 Hospital Management System

A Java console-based Hospital Management System that helps manage patient records using Object-Oriented Programming concepts.

---

## Features

- ➕ Add Patient
- 👀 View Patient Records
- ❌ Delete Patient
- 🗄️ MySQL Database Script
- 📋 Console Menu

---

## Technologies Used

- Java
- OOP
- ArrayList
- Scanner
- MySQL
